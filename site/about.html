Project / About

A reference file, not a buyer's guide.

Vehicle Info is a student-built static website about eight India-market cars and motorcycles. It is designed to show specification research, editorial judgement and front-end craft.

01 / Scope

What this is.

Four cars and four motorcycles, chosen across price bands and body styles. The common thread is that each one has a clear place in the Indian market and enough published data to support a proper file.

Why these eight

The cars run from the Swift, a compact value hatchback, to the City, a larger sedan with a strong-hybrid option. The Creta and XUV400 represent the two directions of the compact SUV market: petrol and electric.

The motorcycles run from the Splendor Plus, the default commuter, to the Himalayan 450, a 196 kg adventure bike. The Classic 350 and 390 Duke cover the retro and naked-sport middle.

How the files are made

Each file begins with the manufacturer's India website, brochure, price list or owner's manual. Where a manufacturer publishes two values, both are recorded. Where a value is missing, the file says so instead of quoting an unverified number.

The result is a snapshot, not a live database. Prices are ex-showroom Delhi as of November 2026. They exclude insurance, registration, road tax and offers.

What is not here

  • No road tests, lap times or subjective ride verdicts.
  • No on-road prices, insurance quotes or resale values.
  • No recommendations about which vehicle to buy.
  • No current NCAP rating where the agency has not tested the car. Previous-generation results are labelled as context only.

Technical notes

The published site is plain HTML and CSS, generated from a local content build. There is no JavaScript, no analytics and no third-party embed. Fonts are self-hosted: Overpass and Overpass Mono, both under the SIL Open Font License. Photographs are Creative Commons or public-domain images from Wikimedia Commons, cropped and resized for the web; each one is credited on the page where it appears.

The layout uses CSS grid, custom properties and fluid type. It respects reduced-motion preferences and keeps a visible keyboard focus style. All specifications are repeated in tables rather than being locked inside images.

Colophon

Type: Overpass and Overpass Mono. Palette: paper, ink, signal red and safety yellow. Diagrams: original SVG schematics drawn for this project. Photographs: credited individually. Built as a static GitHub Pages site; the publishable output lives in site/.
